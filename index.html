⚡ Скорость провайдера ⓘ 500 Мбит/с
🚀 Fast Open Ускоряет запуск TLS рукопожатия
🔒 Allow Insecure Разрешить самоподписанные сертификаты (insecure=1)

🚀 Fast Open

Плюсы: Снижает задержку первого запроса (RTT), отправляя данные во время TLS рукопожатия.

Минусы: Может блокироваться провайдером при плохой работе NAT.

🔒 Allow Insecure

Разрешает небезопасные TLS соединения. Используйте только для самоподписанных сертификатов (повышает риск MITM-атак).

📌 Pin SHA-256

Позволяет привязать отпечаток открытого ключа сертификата для повышения безопасности при использовании самоподписанных сертификатов.

📦 MTU

Рекомендуется: 1500 (стандарт для оптоволокна), 1492 (PPPoE), 1350/1200 (мобильный интернет для исключения зависаний).
