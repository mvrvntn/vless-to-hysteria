# ⚡ VLESS → Hysteria2 Converter

Конвертер VPN-ссылок VLESS / XHTTP → Hysteria2.

Один HTML-файл, без зависимостей. Открывается локально или деплоится на любой хостинг.

## Возможности

- Парсинг VLESS и XHTTP ссылок
- Настройки: скорость, Fast Open, SNI, Allow Insecure, Pin SHA-256, Port Hopping, MTU
- Подробная справка по каждому параметру с плюсами/минусами
- История конверсий (localStorage)
- Адаптивный дизайн, тёмная тема
